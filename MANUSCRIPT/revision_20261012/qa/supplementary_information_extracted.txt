revision_assets.py. They read the archived Phase 2–5 evidence and write only the revision directory.
The main audit records SHA256 hashes of its input CSVs. The MCNP inventory records output hashes.
Test bootstrap resampling uses seed 20261012. Lightweight baselines use training-only five-fold CV with
seed42. TheMCNP-filtersensitivityclonesthefrozenRidgepipelineandchangestrainingeligibilityonly.

completed equal-budget optimizer study is documented in Section S8. Nested/repeated development
splits, mesh convergence, and additional time extensions are not reported as completed analyses.

S8. Equal-budget optimizer benchmark
The additional study comprises 100 runs and 6,030,000 candidate evaluations, using frozen dose and
penetration pipelines. It is distinct from the original NSGA-II campaign used to select the thirty solver-
re-evaluated configurations. Each condition uses ten paired seeds, 300 retained designs, and 60,300
evaluations per run. The lower limits are decision-threshold sensitivities only.
The main text reports aggregate results. Table 10 preserves all per-run outcomes. HV uses the fixed
DoE anchors without clipping coordinates better than the DoE ideal. IGD and generalized spread use
the pooled empirical nondominated reference for each limit/margin combination. At 60 mm, the margin
reference pools three methods, whereas the point-only reference contains NSGA-II only. Consequently,
identical NSGA-II fronts can have different IGD values in those two columns of the protocol. Such
differences are reference-set effects, not different solutions.
Table 10: All optimizer runs. Q uses the frozen margin, P
