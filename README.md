# Blindagens para First Responders em Cenários de RDD

Conjunto de dados e códigos computacionais referentes à tese de doutorado em **Engenharia Nuclear** pela **COPPE/UFRJ**. O repositório inclui os scripts de simulação e análise, além dos dados brutos e processados utilizados na pesquisa sobre blindagens para *First Responders* em cenários de *Radiological Dispersal Device* (RDD).

---

## 📋 Descrição

Este repositório reúne todo o material computacional desenvolvido ao longo da pesquisa de doutorado, incluindo:

- **Scripts de simulação** em MCNP para modelagem do transporte de radiação.
- **Scripts de simulação** em LS-DYNA para análise estrutural e de blindagem.
- **Scripts de análise** em Python para processamento dos dados e geração de resultados.
- **Dados brutos** gerados pelas simulações.
- **Dados processados** utilizados na redação da tese.

O objetivo é garantir a **reprodutibilidade** dos resultados apresentados na tese e facilitar a **citação** e o **reúso** do trabalho por outros pesquisadores.

## 🚀 Como Reproduzir

1. Clone o repositório:
   ```bash
   git clone https://github.com/SEU_USUARIO/artigo_tese.git
   cd artigo_tese
   ```

2. Instale as dependências Python:
   ```bash
   pip install -r requirements.txt
   ```

3. Execute os scripts conforme a ordem descrita em `docs/`.

> ✏️ *Ajuste as instruções conforme o seu fluxo real de trabalho.*
